# Guarded Agent Pipeline

**受门控的 Agent 决策层：LLM 提议，确定性规则把关，每条保证都配一条可证伪的测试。**

模型负责预测，决策层负责判断**这个数能不能信** —— 直接报告、建议复测，还是转参考方法。
本仓库是这一层：模块化流水线，LLM 提议处置动作，8 条确定性规则逐条把关，
不通过则回退规则决策。

> **范围**：本仓库只含决策层。流水线消费模型给出的 `(ŷ, σ)`，不检查模型内部。
> 附带合成数据生成器，无需私有数据集即可完整运行。

## 快速开始

```bash
pip install -r requirements.txt

python code/mems_data.py            # 查看合成数据集
python demo/run_demo.py             # 决策层端到端演示
python examples/show_cases.py       # 门控拦截案例（建议先看这个）
python agent_system/run_tests.py    # 测试套件
```

门控拦截的具体轨迹见 [`examples/`](examples/README.md)：五类违规各一段运行输出。

**不需要 API 密钥。** 没有 `LLM_API_KEY` 时所有 LLM 组件降级到确定性规则路径，该回退路径同样被测。

## 架构

```
                    上游模型（不在本仓库范围）
                              │  ŷ, σ
                              ▼
   ┌──────────────────────────────────────────────────────────┐
   │  A4  评估      保形区间 ▸ RPD 分级                         │
   │  A5  路由      预算约束下的复测规划                        │
   │  A5b 门控      LLM 提议 ▸ 8 条门控 ▸ 不通过则回退规则       │
   │  A5c 审议      提议 ⇄ 质疑 ⇄ 修订（≤3 轮）                 │
   │  A6  报告      结构化文本，数值可溯源                      │
   │  V   校验      读取真值的环节                              │
   │  A7  回流      标记高价值样本供人工复检                    │
   └──────────────────────────────────────────────────────────┘
```

两个 Agent 持有不同的数据访问权与不同的能力：

| Agent | 能做什么 | 看不到什么 |
|---|---|---|
| **A5b 决策 Agent** | 选择处置动作；查询结构化字段 | 光谱数据 |
| **A1 感知 Agent** | 检查光谱（尖峰/饱和/NaN） | 决策依据 |

A5b 通过 `request_spectral_recheck` 向 A1 请求光谱结论。
实测 8 个样本中有 2 个触发了该跨 Agent 请求。

## 门控规则

| 规则 | 拒绝什么 |
|---|---|
| G1 | 动作不在 `{report, retest, reference}` 内 |
| G1b | 缺少某个目标 |
| G2 | 对不可报告目标给出 `report` |
| G3 | 整个模型族退化时仍 `report` |
| G4 | 理由码不在允许集合内 |
| G5 | 提议中出现了任何工具从未返回过的数 |
| G6 | 当 `report` 的期望损失最高时仍选择 `report` |
| **G7** | *(批量级)* 提议集合的复测数超过预算 |

每条规则配一条反例测试，覆盖 7 条逐样本规则 + 1 条批量规则。

**G7 处理的是逐条合法与整体可行之间的落差。** 10 条各自合规的提议可能合起来击穿预算。
10 个样本全部提议 `retest`、预算 20% ⇒ 最终 2 个保留，8 个回退规则。

## 实测结果（原始数据集）

以下数字在原始研究数据集上测得。原始数据集不可再分发，本仓库以合成数据复现其结构。

| 论断 | 实测 |
|---|---|
| 可靠性信号排序误差的能力 | Spearman ρ = **0.165–0.196**（p < 0.01） |
| 信号相对工业启发式的优势 | AURC **+19.8% … +26.5%**；5 组阈值、100 次随机抽样（P = 0.99–1.00）、5 个预算点全部成立 |
| 信号组合 | 9 种组合全部低于单用 σ（−3% … −32%） |
| 保形校准 | 名义 90% ⇒ **90.3%**；名义 95% ⇒ **95.1%** |
| 进程隔离 | 3 个 worker，`module_arrays=0`；阴性对照检出泄漏（2 vs 0） |
| 故障行为 | worker 被杀 → 3.01 s；挂起 → 2.01 s；越权字段 → `PermissionError`；错误后组件仍可用 |
| LLM 忠实性 | CFS **21.8%**（n=124，95% CI 15.4–29.8%）；概念判断准确率 **46.7%**（n=75，CI 35.8–57.8%） |
| LLM 决策增益 | Δ = **−0.002**（不显著）—— 价值在可解释与安全 |

## 设计要点

### LLM 提议，规则决策

实测概念级决策准确率 **46.7%**（95% CI 35.8–57.8%，三分类随机水平 33%），
概念消融翻转率（CFS）**21.8%**。前者决定 LLM 不单独决策，后者决定不弃用 LLM：
概念确实驱动约五分之一的决策，因此保留其提议能力，由规则把关。

### 报告数字的可溯源校验

`verify_numbers_strict` 抽取渲染文本中的每个数字，要求它能追溯到某个结构化字段，
且只接受模板实际输出的格式。两个方向都被测：缺失的数字与编造的数字。

### 三分类的适用边界

决策层的三分类在成本比 `c_test / E|err|` 落入 **[0.20, 2.00]** 时成立。
区间外三分类退化为单一策略（全报告或全复测），此时决策层的价值需要重新论证。

### 隔离的层级

系统当前提供载荷级隔离：父进程只发送白名单字段，越权字段直接抛错，
worker 模块级不含数据数组。文件系统级隔离需要容器或权限边界。

## 测试

```bash
python agent_system/run_tests.py
```

```
TOTAL  72 项通过  |  18 个套件跳过（需原始数据）
```

| 类型 | 无数据可跑 | 覆盖内容 |
|---|---|---|
| **逻辑类** | ✅ | 8 条门控各配一条反例、审议环收敛、报告模板、数值溯源、置信区间、指标解析值（1.60 / 3.20） |
| **数据锚点类** | ⏭ 跳过 | 断言原始数据集实测值的套件（gap = 0.0324、覆盖率 = 90.3% 等） |

数据锚点类套件钉住的是应在真实数据集上复现的数值。缺数据时它们显式跳过并打印原因；
放入 `experiments/` 即可运行，见 `run_tests.py` 中的 `DATA_MARKERS`。

## 局限

- 上游回归模型不在本仓库；demo 用岭回归替代。
- 隔离为载荷级，文件系统级隔离需容器或权限边界。
- 三分类在 `c_test / E|err|` 超出 [0.20, 2.00] 时退化。
- LLM 组件在 25 个样本（75 次判断）上评估，比例型结果同时给出置信区间。
- 报告可读性未做用户研究。
