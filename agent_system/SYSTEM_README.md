## 一、这是什么

一个把 **NIR 点预测** 变成 **可审计质量决策** 的流水线。

模型（v39）给出 5 个成分的预测，但实验室真正的问题是：
**"这个结果，我敢不敢用来定价 / 分群 / 拒收？"**

本系统回答这个问题，输出：
- 每个目标的**保形预测区间**（覆盖率 90.3% @ 名义 90%）
- 每个目标的**可报告性分级**（Fat/Prot/TS 可报告；Lact/Urea 不报数值）
- 每个样本的**处置决策**（直接报告 / 建议复测 / 转参考法）
- **人类可读的报告**（数值由代码插入，LLM 只改措辞）

### 两条铁律

```
① **载荷隔离**：父进程只发白名单字段（越权抛错），worker 模块级无数据数组（阴性对照可检出）；⚠️ 不阻止 worker 读磁盘文件
② 数值链路中不得出现 LLM —— 所有数值/区间/分级/决策由确定性代码产生
```

### 4.4z Guarded Agent（LLM 提议 + Tool Use + 门控）

| 指标 | 结果 |
|---|---|
| 门控采纳率 | **100%**（12/12） |
| 工具调用 | **18 次/样本**（14–19）← 真 ReAct 循环 |
| 决策与规则一致 | 11/12 |
| 真实损失 Δ | **−0.00208**（不显著） |
| 门控规则数 | **7 条逐样本 + 1 条批量（G7 预算）**，每条都有阴性对照 |
| G7 预算门控 | 10 样本全 retest、预算 2 ⇒ 最终 **2** 个、回退 **8** 个 ✅ |

```
⭐ 价值不在"更准"，而在"可解释 + 安全"：
```

|---|---|

该限制由上述测量直接支持，而非出于保守。

## 五、诚实边界（必须随结论一起报告）

```
① 调度/隔离/校验是工程基础设施，**不是科学贡献**
② **线程级并发对 GPU 任务无加速收益（实测 0.99–1.14×）**；
   吞吐杠杆在**批量推理**（batch=60 时每样本 0.29 s，比小批快 6.1×）；
   并行架构的真实价值是**失败隔离 + 多 GPU 可扩展性**
③ 采集 Agent 的"工具调用"是**模拟**（无真实仪器接口）；异常为**注入**
④ 分档阈值是**固定的管理规划值**（非国标、非拟合）；合规限值用真实国标
⑤ 回流验证仅在**低数据量情景**成立
⑥ LLM 无可读性用户研究（只用关键词覆盖作代理）
⑦ 5/8 个组件本质仍是规则/函数 —— 文档已照实区分
```
